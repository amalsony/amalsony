# Hey, I'm Amal 👋

Computer Science junior at **Penn State** building web and mobile apps used by over 4000 people and exploring how to make LLMs more useful as a undergraduate researcher at the Penn State NLP Lab.

I like taking ideas from a rough prototype to something people actually use. My work spans full-stack development, open-source tools, and LLM research.

### A few things I've built

- 👕 **[WardrobeAI](https://www.wardrobeai.app)** — An AI wardrobe and outfit app used by **4,000+ people** to organize **14,000+ clothing items**.
- 📝 **[UniversalNotes](https://www.universalnotes.org)** — An open-source browser extension bringing Community Notes-style fact-checking to websites beyond X. [Source ↗](https://github.com/amalsony/universalnotes)

### My research at the Penn State NLP Lab

LLM activation steering and evaluation through undergraduate research at **Penn State's NLP Lab**, working with Qwen and Gemma models.

**Tools I work with:** TypeScript · Python · React · Next.js · React Native · Node.js · MongoDB · vLLM
